# 排版规范

> 数值见 `tokens/primitives.json → typography`。

## 原则

**层级靠字重与颜色驱动，不靠字号堆叠。** 正文与 UI 文字集中在 11.5–14px 的小区间；**标题一律 w700**（含专辑 / 艺人 / 正在播放 hero），**w800 仅用于瞬时强调**（选中态、当前歌词、monogram 等），禁止把整页标题做成 w800。

## 字族

- **主字族：平台默认**——`ThemeData` **不**设置 `fontFamily` / 不钉 `.SF Pro Text`。
- 各平台自然解析：Apple → SF / 苹方；Android → Roboto / Noto；Windows → Segoe UI / 微软雅黑。
- **不打包字体文件**，不维护强制 fallback 列表（避免主字体缺失时中英文 metrics 错位）。
- 内容层（开卷书页正文）可有独立字体栈与字号体系（Georgia/宋体等），属 L0 扩展，不受本篇约束。

## 字重阶梯

| 角色 | 字重 | 颜色档 | 说明 |
|---|---|---|---|
| **选中 / 当前强调** | **w800** | primary 或 accent | 底栏/侧栏选中标签、chip 选中、索引当前字母、队列正在播曲名、**歌词当前行**、艺人 monogram |
| 页标题 / hero / sheet 标题 / 分区标题 | **w700** | primary | 设置页头、专辑/艺人详情标题、正在播放曲名、迷你播放器曲名、弹层标题 |
| 强调（正文强调、次级按钮、未选 chip） | w600 | primary / secondary | |
| 正文 | w400 | primary | |
| 辅助说明 | w400 | secondary / muted | |

**禁止 w900。** 需要「更重」时用字号或颜色，不要用更粗字重。

## 内容层展示（display tier）

沉浸页允许**略大于壳层**的标题字号，但**字重仍封顶 w700**（与壳层标题同档）：

| 场景 | 字号 | 字重 | letterSpacing |
|---|---|---|---|
| 桌面 hero（专辑 / 艺人 / 合集） | 28 | w700 | −0.3 |
| 移动沉浸 hero | 24 | w700 | −0.25 |
| 正在播放曲名 | 24 | w700 | −0.25 |
| 歌词（内容） | 18–22 | 当前 w800 / 其余 w700 | 0 |

- 展示层级只用于内容标题本身；同页艺人名、元信息走壳层三档（hero 艺人名定档：15 w600 secondary，可点击跳转但不染 accent）；
- 大字号展示文字**不得**用 accent 色；
- 歌词窄栏（列宽 < 340）字号可降一档，并用平衡换行避免单字成行（参考开听 `BalancedLyricText`）。

## 规则

1. **标题 = w700**；**w800 仅选中 / 当前 / monogram**，不得用于页头与 hero。
2. 标题负字距缓和（约 −0.1～−0.3）；正文与行文字不加字距。
3. `bodySmall` 默认染 secondary 色（TextTheme 层约定）——需要 primary 色的小字必须显式指定。
4. 数字与进度标签可用 tabular figures；中英文混排不额外加空格。
5. 截断：行标题单行省略；说明文字最多两行；对话框标题单行省略。
6. 禁止钉死 `.SF Pro Text` 作为唯一主字体。
