# 排版规范

> 数值见 `tokens/primitives.json → typography`。

## 原则

**层级靠字重与颜色驱动，不靠字号堆叠。** 正文与 UI 文字集中在 11.5–14px 的小区间，用 w600→w700（壳层标题）与 primary→secondary→muted 表达主次；只有内容层沉浸标题可上到 w800 + 较强负字距。

## 字族

- **主字族：平台默认**——`ThemeData` **不**设置 `fontFamily` / 不钉 `.SF Pro Text`。
- 各平台自然解析：Apple → SF / 苹方；Android → Roboto / Noto；Windows → Segoe UI / 微软雅黑。
- **不打包字体文件**，不维护强制 fallback 列表（避免主字体缺失时中英文 metrics 错位）。
- 内容层（开卷书页正文）可有独立字体栈与字号体系（Georgia/宋体等），属 L0 扩展，不受本篇约束。

## 字重阶梯

| 角色 | 字重 | 颜色档 |
|---|---|---|
| 内容层展示（沉浸 hero、曲名、当前歌词） | w800 | primary，较强负字距 |
| 壳层页标题 / 对话框标题 / 强调标题 | w700 | primary，缓和负字距 |
| 强强调（选中导航、主按钮、行标题） | w600–w700 | primary 或 accent |
| 强调（正文强调、次级按钮、chip） | w600 | primary / secondary |
| 正文 | w400 | primary |
| 辅助说明 | w400 | secondary / muted |

## 内容层展示层级（display tier，已登记扩展）

沉浸式内容页（合集详情 hero、专辑详情 hero、正在播放曲名）允许突破壳层字号上限，**字重封顶 w800**，负字距可取内容档：

| 场景 | 字号 | 字重 | letterSpacing |
|---|---|---|---|
| 桌面 hero（合集/专辑标题） | 38 | w800 | −0.8 |
| 沉浸头 / 移动 hero | 28–34 | w800 | −0.55（≥30 可用 −0.8） |
| 正在播放曲名 | 27 | w800 | −0.55 |
| 歌词行（内容） | 20–22 | 当前行 w800 / 其余 w700 | 不加字距 |

- 展示层级只用于内容标题本身；同页的艺人名、元信息仍走壳层三档（hero 艺人名定档：15 w600 secondary，可点击跳转但不染 accent）；
- 大字号展示文字**不得**用 accent 色（强调色只用于选中/进度/主操作）；
- w900 全局禁用——超出 w800 的「更重」需求一律用字号或颜色解决。

## 规则

1. **壳层**大标题用缓和负字距（约 −0.1～−0.25）；**内容层**沉浸标题才用较强负字距（−0.55 / −0.8）。正文与行文字不加字距。
2. `bodySmall` 默认染 secondary 色（TextTheme 层约定）——实现时注意：不显式设样式的小字自动变灰是**特性**，需要 primary 色的小字必须显式指定。
3. 数字与进度标签可用 tabular figures；中英文混排不额外加空格（交给系统排版）。
4. 截断：行标题单行省略；说明文字最多两行；对话框标题单行省略。
5. 禁止钉死 `.SF Pro Text` 作为唯一主字体——跨平台会掉进不一致的 fallback，观感「怪」。
