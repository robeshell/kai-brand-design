# 数据展示（Card / Tag / Avatar / Thumbnail / Table）

- **用途**：用稳定的结构展示信息、状态、人物或多列数据。
- **不用**：不要用卡片包住页面上的每一块内容；只有一列简单内容时优先使用列表行。

## 变体

| 变体 | 用途 |
|---|---|
| 信息卡片 | 一组有明确边界、可以独立理解的信息 |
| 标签与状态 | 简短分类或状态，文字必须能单独说明含义 |
| 头像与缩略图 | 帮助识别对象，图片缺失时显示稳定的占位内容 |
| 表格 | 比较多条记录的相同字段 |

## 状态

| 状态 | 规则 |
|---|---|
| 默认 | 标题、说明和辅助信息层级清楚 |
| 加载 | 保留结构，避免内容出现时整体跳动 |
| 空 | 说明当前没有数据；有明确下一步时再给操作 |
| 错误 | 说明失败原因，并提供重试或修正方式 |

## 无障碍

- 状态标签不能只靠颜色表达含义。
- 图片需要替代文字；装饰图片使用空替代文字。
- 表格需要表头，排序状态需要提供给辅助技术。
- 内容缩放到 200% 时，信息不能被截断或重叠。

## 验收锚点

- 卡片使用 `radii.card`，不自行增加阴影层级；
- 标签文字不小于正文辅助字号；
- 表格行与表头保持清楚的对应关系。
