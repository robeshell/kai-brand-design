# 开卷分叉登记（divergences）

> 开卷对品牌层的有意偏离。内容渲染本身属于 L0 扩展点；只有它影响到 chrome 或通用组件时才在此登记。

| # | 偏离 | 理由 | 方向 |
|---|---|---|---|
| D1 | 图书阅读器 chrome 取色自当前阅读主题，而非 App 皮肤 token | 工具条覆盖在 paper / sepia / dark / pureBlack 书页上，必须与书页形成稳定可读关系；切换 App 皮肤不应改变书页语境 | 保留；仅限阅读器 chrome，退出阅读器即恢复品牌皮肤 |
| D2 | 阅读内容层允许书内 CSS、阅读高亮色板与必要的字面颜色 | EPUB 作者样式、选区高亮和漫画像素不是壳层 UI；强制映射品牌 token 会破坏内容与可读性 | 保留；禁止泄漏到书库、设置、对话框等壳层 |
| D3 | 图书阅读器包含 WebView / Platform View，个别弹层需要指针拦截或原生层级适配 | 平台视图可能吞掉 Flutter 浮层事件，这是渲染技术约束，不是新的视觉样式 | 保留实现适配；视觉仍遵循品牌 sheet / overlay |
| D4 | 书籍 / 漫画封面使用 r12，不跟品牌通用 card r14 | 窄幅竖向封面上 r14 占短边比例偏高，视觉过圆；封面属于内容层框架，普通 UI 卡片不受影响 | 保留为产品 token；见 `tokens.md → cover.radius` |

- ~~两个 flavor / 两个产品~~ → 一个安装包、一个数据域、漫画与图书双引擎；`main_book.dart` / `main_comic.dart` 仅为兼容入口；
- ~~桌面侧栏固定 220~~ → 品牌 0.2.6 的 medium 216 / wide 236。
