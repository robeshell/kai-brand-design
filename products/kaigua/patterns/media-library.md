# 媒体资料库（开刮）

> 对应 `desktop/src/App.tsx` 的侧栏、海报/列表视图和筛选工具栏。

## 信息架构

侧栏按资料源与媒体类型组织，底部放日志、重命名和设置等工具入口。电影、剧集、动画是
同一资料库的筛选，不复制三套页面结构。

## 主页面

```
[Toolbar：搜索 / 筛选 / 排序 / 海报·列表切换]
[媒体列表或海报网格]
[右侧详情栏，可选]
```

- 海报视图用于浏览识别，列表视图用于比较路径、状态和更新时间；
- 结果数放 Toolbar；不做大号统计卡；
- 宽屏选择条目打开右侧详情栏，首选宽 420；窄屏进入独立详情；
- 右键菜单与“更多”菜单使用同一 action model。

## 状态

- 未配置目录：主操作为添加媒体目录；
- 空目录：说明扫描范围并提供重新扫描；
- 无筛选结果：保留目录，提供清除筛选；
- 海报加载失败保留比例和占位，不能导致网格跳动；
- 扫描运行时已有媒体仍可浏览。
